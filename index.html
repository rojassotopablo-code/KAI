KAI espera este silencio antes de enviar lo que dijiste. Súbelo si te corta a mitad de frase.

Forma recomendada en el celular: toca el orbe una vez y conversa de corrido; KAI sigue escuchando después de cada respuesta hasta que digas «gracias» o te quedes en silencio. La escucha continua con «KAI» hace sonar un «bip» en Android cada vez que reinicia el micrófono; para no molestar, se pausa sola tras 3 minutos sin voz. Ese bip se puede bajar con el volumen de sonidos del sistema/notificaciones del teléfono.

Sincronización entre dispositivos

Sin configurar
Tus proyectos, agenda, notas y creaciones se guardan en un repositorio privado de tu GitHub y aparecen en todos tus dispositivos.
Configurar en este dispositivo
  1. Crea un repositorio privado llamado kai-datos: abrir GitHub → Create repository.
  2. Crea una llave de acceso: abrir GitHub → nombre «KAI» → en Repository access marca primero Only select repositories y elige kai-datos (los permisos aparecen recién después de esto) → en Permissions toca Add permissions (o abre Repository permissions), elige Contents y cambia su acceso a Read and write → Generate token y cópiala.
    ¿No aparece? Usa la llave clásica, más simple: abrir llave clásica → deja marcado repo → Generate token.
  3. Pégala abajo y toca Conectar. En los demás dispositivos usa «Vincular con código QR».

En el celular: apunta con la cámara normal del teléfono a este código y toca el enlace que aparece: KAI se abre ya vinculado. (También sirve Ajustes › Vincular con código QR.) Incluye tu llave de GitHub y tu API key: no lo compartas con nadie.
